# Proof Readiness v1

Proof readiness reports replay, checkpoint, journal, receipt, root, transition, touched-state, invariant, deterministic numeric model, component commitment, and future ZK witness compatibility status. ZK statuses are `NOT_REQUESTED`, `STRUCTURALLY_COMPATIBLE`, `REQUIRES_PROFILE`, `UNSUPPORTED_FEATURE`, and `UNBOUNDED`. The compiler never claims a ZK proof exists.

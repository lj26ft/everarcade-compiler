# Attestation status under trust-root v2 (sidecar registry)

This registry gives each committed attestation record an explicit status under `everarcade-review-root-v2`. It is a sidecar: **the export files listed here are not edited, re-signed or deleted**, and no pinned hash changes. Identities are given at base `33aa49b51d2095d2154049761d4b1734d9f85fc7` as git blob id and SHA-256 of the file bytes.

## Status values

| Status | Meaning |
|---|---|
| `COMPROMISED_TEST_FIXTURE` | Signed by the revoked v1 fixture key (SPKI DER SHA-256 `6858d411f4f7ef9962de02945a7197ad9994903ec734627701cd1fb79968cd9c`). Never valid, and refused in production. **No committed record has this status.** Such attestations are created in each CI run and are not committed. |
| `HISTORICAL_UNVERSIONED_NOT_V2` | A committed review export or failure fixture (schema V0 / V0_1_RC1 / V0_1_RC2) with no signed `trust_root_version`. Kept byte-for-byte as evidence of what was produced. Not trust-root-backed. Any `PASS` text inside is historical, not a v2 verification result. |
| `MUST_FAIL_FIXTURE` | Applies in addition to the status above, for `failure-fixtures/*` records. The expected FAIL is unchanged. |
| `HISTORICAL_SELF_ATTESTED` | A proof record whose `attestation_verification: PASS` came only from the key embedded in the attestation (finding H-2). No trust root was consulted. |

None of the 32 attestation records below embeds the revoked fixture key. Their `attester.public_key` values are other keys, none of which is in v1 or v2.

## Rules

- No record listed here can be v2-backed: none carries a signed `trust_root_version`, and v2 has no active key.
